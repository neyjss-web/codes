📑 PDF Notas
—

Arraste um PDF para cá

ou use Abrir PDF. Depois, importe/exporte comentários em FDF.

  • < > diminuem/aumentam as páginas na tela
  • Passe o cursor sobre uma página para ampliá-la e destacar os comentários
  • Clique nas páginas para selecioná-las (Shift+clique seleciona um intervalo) e marque todas com um comentário único
  • Clique duplo abre a página para ler o texto e comentar

    Realçar/Sublinhar/Tachar: selecione o texto com a ferramenta ativa, ou arraste um retângulo em áreas sem texto. As marcações de grupo são gravadas como notas padrão do PDF (com moldura opcional) e exportadas no FDF com identificador grp-…, o que permite reimportá-las como grupo.
